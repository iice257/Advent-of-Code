# Advent of Code

This branch keeps the simulated day-folder layout, but the committed JavaScript files now contain real puzzle-solving logic.

## Layout

Each completed day lives in one folder:

```text
YYYY/Day N - Done/
  input.txt
  Test 1.js
  Test 2.js
```

- `Test 1.js` prints the part 1 answer.
- `Test 2.js` is present only when that puzzle has a real part 2 to solve.
- Every committed JS file reads the sibling `input.txt` directly.
- Each committed JS file contains the actual day solver source plus a small Node runner.

## Coverage

- JavaScript is available from `2015 Day 1` through `2025 Day 12`.
- Day 25 folders keep only `Test 1.js`, because those years do not have a separate coded part 2 on this branch.
- The fake Python wrappers have been removed.

## Commands

```bash
npm run solve -- 2015 1
npm run solve -- 2015 1 2
npm run answers
npm run provenance
npm run verify
```

## Source Notes

- Official Advent of Code session access is not configured in this environment.
- Inputs are mirrored from a public source and tracked in `provenance.json`.
- Solver files are materialized from the matching cached solver modules already present under `.cache/upstream/shahata`.
- `answers.json` is generated by running the committed `Test 1.js` / `Test 2.js` files, not by a shared manifest reader.
