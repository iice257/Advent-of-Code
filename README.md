# Advent of Code 2015

I'm just starting to try out these Advent of Code challenges! They seem like a great way to practice and hone my JavaScript skills, and I'm looking forward to working through them.

The plan is to solve them from the very beginning (2015, day 1) all the way to the latest one (2025 at this time), and continue whenever there's a new one december each year.

The main constraint is that while i'm allowed to google some simple things, there will be no use of AI help whatsoever otherwise this whole thing would be pointless (I even turned off AI on my google searches).

Each day's solution will be in its own folder.

There will obviously be more elegant solutions out there, or shorter, or more efficient, or cleaner, or faster, or ... okay you get the point. But i'm not aiming for any of that, my number 1 goal is to solve the problems, full-stop. Any other objective is secondary.
